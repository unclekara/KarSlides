# KarSlides – portable-версия

Автор: Aleksandr Karabatov, hellokarabatov@gmail.com. Версия – в имени папки, в шапке пульта, в трее (первая строка меню) и в свойствах `KarSlides.exe`. История изменений – `CHANGELOG.md`.

KarSlides держит PowerPoint в фоне, запускает показ на виртуальном мониторе и отдаёт его в vMix по NDI®: с анимациями, переходами, видео и звуком. vMix при этом остаётся в фокусе.

Папку можно положить куда угодно (например, `C:\KarSlides`). .NET ставить не нужно, он внутри.

## Что нужно на машине

1. Windows 10 21H2+ или Windows 11, x64.
2. Microsoft PowerPoint (настольный, Microsoft 365 / 2019 / 2021 / 2024). На эфирной машине PowerPoint должен быть только у KarSlides: при зависании KarSlides перезапускает **все** процессы `POWERPNT.EXE`. Не открывайте презентации в PowerPoint, пока работает KarSlides: процесс PowerPoint у них общий, и любой открытый документ ставит показ на паузу. После этого видео в показе не запускается, пока презентацию не перезагрузить в пульте. KarSlides предупредит об этом в «Проблемах». С опцией «Сторожевой таймер → Перезапускать показ, поставленный на паузу» он сам перезапустит показ на той же позиции, когда документ закроют; в эфире на ~4 с будет стоп-кадр.
3. **NDI 6 Runtime** (ставится вместе с NDI Tools: https://ndi.video/tools/). В папку KarSlides он не входит.
4. Монитор для показа **1920×1080**: виртуальный (например, Virtual Display Driver) – рекомендуется; или HDMI-заглушка; или отдельный монитор. Выбирается в пульте: Настройки → Показ → «Монитор показа». Не основной монитор и не тот, куда vMix выводит Fullscreen.
5. Звук: у устройства, куда играет PowerPoint, выключить «Улучшение звука» (Параметры → Система → Звук → устройство). Иначе звук видео отстаёт от картинки на 20–40 мс. KarSlides предупредит, если улучшения включены. Устройство выбирается в пульте: Настройки → Звук → «Куда PowerPoint играет звук здесь». В NDI звук идёт при любом выборе. Чтобы в комнате было тихо, выберите устройство, которое никуда не выводит.

## Запуск

1. `KarSlides.exe`. При первом запуске Windows спросит доступ к сети: разрешить (порт 9180, пульт и API).
2. В трее появится иконка. Двойной клик – окно состояния (адрес API, имя NDI, проблемы).
3. Трей → **Operator panel** – веб-пульт. С других устройств: `http://<ip-машины>:9180/`.
4. В vMix: Add Input → NDI → `<ИМЯ-ПК> (KarSlides - Slot 1)`.
5. Экран спикера: кнопка «Экран спикера» на пульте или `http://<ip>:9180/presenter/1`.

Выход: трей → Exit (PowerPoint закроется сам).

## Язык

Пульт, экран спикера и настройки – на русском или английском: переключатель RU | EN в шапке. Выбор запоминается в каждом браузере отдельно, так что у оператора и спикера язык может быть разным. Без выбора – язык браузера.

## Кликер

Пока в пульте горит «Кликер: ВКЛ», **PageDown** листает вперёд, **PageUp** – назад, даже когда в фокусе vMix. Эти две клавиши до vMix не доходят. Остальные клавиши (пробел, стрелки, буквы) кликер не трогает, так что титры в vMix можно набирать спокойно.

## Настройки

Проще всего – в пульте: шестерёнка справа вверху → поменять → «Сохранить» → «Перезапустить». Пульт сам проверит значения и запишет их в `%APPDATA%\KarSlides\settings.json`.

Тот же файл можно править руками. `appsettings.json` рядом с exe – настройки по умолчанию с пояснениями. Свои значения лучше класть в `settings.json`: они перекрывают `appsettings.json` и не потеряются при обновлении папки. Например:

```json
{
  "Paths": { "Inbox": "D:\\Презентации" },
  "Slots": { "Monitors": [ "virtual" ] }
}
```

- vMix находится автоматически: KarSlides сам ищет порт Web Controller среди портов запущенного vMix. В vMix должен быть включён Web Controller (Settings → Web Controller). Число вместо `0` в `Vmix.HttpPort` нужно только для vMix на другом компьютере (вместе с `Vmix.Host`).
- `Paths.Inbox` – папка, из которой пульт предлагает файлы.
- `Slots.Monitors` – монитор показа (удобнее выбрать в пульте): `virtual` (первый виртуальный), DeviceID монитора или его часть, или `\\.\DISPLAYn`.
- `Clicker.Next` / `Clicker.Prev` / `Clicker.Black` – клавиши кликера.
- `Output.Fps` – 25, 29.97, 30, 50, 59.94 или 60 (как в проекте vMix).
- `Preview.Live` – живая картинка (анимации, видео) на пульте и у спикера; `Preview.Fps` (25) и `Preview.Width` (960) – частота и размер. На слабой машине или медленном Wi-Fi уменьшить или выключить (`false`): останутся миниатюры.
- `Show.Topmost` – окно показа поверх всех окон на своём мониторе (по умолчанию `true`): случайно перетащенное туда окно не попадёт в эфир.

После изменения настроек перезапустить KarSlides.

## Если что-то не так

- Окно состояния и `http://localhost:9180/api/state` → раздел `problems`.
- Логи: `%LOCALAPPDATA%\KarSlides\logs\karslides-<дата>.log`. Подробный лог: `"Logging": { "Level": "Debug" }` в settings.json.
